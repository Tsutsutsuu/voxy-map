# 构建与发布

## 环境

| 项 | 值 |
| --- | --- |
| 构建 JDK | `C:\Users\Tsutsutsu\.jdks\jdk-21.0.12.1+1` |
| 游戏启动 JDK | Java 25（实例要求，c2me class file 69） |
| 代理 | 127.0.0.1:7897（已写入 mod/gradle.properties） |
| NeoForge | 21.1.217（build.gradle） |
| 目标实例 | `D:\Minecraft\AxolotlLauncher\Data\profiles\1.21.1-NeoForge 21.1.265` |

## 构建命令

```powershell
$env:JAVA_HOME='C:\Users\Tsutsutsu\.jdks\jdk-21.0.12.1+1'
$env:Path="$env:JAVA_HOME\bin;"+$env:Path
$env:GRADLE_OPTS='-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=7897 -Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=7897 -Xmx3g'
cd mod
.\gradlew.bat build --no-daemon --no-configuration-cache
```

产物：`mod/build/libs/voxy-map-0.1.0.jar`

## 安装

```powershell
Copy-Item -LiteralPath "mod\build\libs\voxy-map-0.1.0.jar" `
  -Destination "D:\Minecraft\AxolotlLauncher\Data\profiles\1.21.1-NeoForge 21.1.265\mods\voxy-map-0.1.0.jar" -Force
```

改完 jar 必须**重启游戏**（客户端模组不支持热重载）。

## 版本与缓存

- mod 版本：`0.1.0`（build.gradle 的 mod_version）。
- `MapData.CACHE_VERSION`：**任何影响像素内容的改动都要 +1**（合并规则、pixelBlocks 默认值、海平面逻辑等），否则旧缓存会让用户看到旧数据。
- 历史：v3（biome 名称表）、v4（名称修复）、v5（洞穴高度修复）。

## 发布检查清单

1. `gradlew build` 通过。
2. jar 里包含：lang（en_us/zh_cn）、纹理 arrow_clean/arrow_classic、无残留 shader。
3. 实例 mods 目录替换 jar 后启动，进游戏开地图验证：位置对准玩家、缩放 = 配置值、群系正常、无崩溃。
4. 若改了合并/缓存逻辑：升 CACHE_VERSION，并在游戏内点一次刷新（或首次打开自动重建）。
