# 技术笔记

## 1. Voxy 数据格式

### section 存储
- RocksDB（只读打开），列族：`world_sections`、`id_mappings`。
- key（大端 8 字节）：`(lvl<<60) | ((y&0xFF)<<52) | ((z&0xFFFFFF)<<28) | ((x&0xFFFFFF)<<4)`
  - 解码：`lvl=(key>>>60)&0xF`、`x=(int)((key<<36)>>40)`、`y=(int)((key<<4)>>56)`、`z=(int)((key<<12)>>40)`
- 值：ZSTD 帧 → 体素数组 long[32768] + LUT（`short[32768]` + `long[lutSize]`）。
- 体素：`light(byte)<<56 | biome(9bit)<<47 | blockId(20bit)<<27`
  - airMask = `((1L<<20)-1)<<27`；空气 = `(voxel & airMask) == 0`
  - biome = `(voxel>>>47)&0x1FF`

### id_mappings
- 4 字节 key，前缀：`0x40` = block_state，`0x80` = biome。
- biome 值 = GZIP 压缩的 NBT 文本（含注册名）；id = `key & 0x3FFFFFFF`。
- mod 群系无命名空间：`:woodland`；名称表提取时允许 `[a-z0-9_:.-]`，去掉尾部 `.`。

### 合并 packed long（每地图像素）
- `lvl<<48 | (topFluid?1<<52:0) | ((top+32768)<<24) | ((floor+32768)&0xFFFF) | ((long)biomeId<<53)`
- 哨兵：NO_SOLID=-32768、NO_TOP=-32767。

### 缓存 .vxm 格式
magic(4)=0x56584D31 + CACHE_VERSION(4) + w(4) + h(4) + minWX(8) + minWZ(8) + pixelBlocks(4) + mtime(8，写 0) + bioN(4) + (id(4)+UTF name)*(N) + clen(4) + zstd(long[w*h])。

## 2. 合并算法（flushSection）

对每个 section 的每一列：
- 找 top（最高非空气）和 topFluid（top 是水，来自 waterIds 表）；找 solid（最高非水固体）。
- 地下切片：`topY==31 && !topFluid` → top=NO_TOP。
- 接受规则（顺序）：
  1. `curTop == NO_TOP || lvl < curLvl || (lvl==curLvl && top>curTop)` → 接受。
  2. **同层固体补全**：`lvl==curLvl && solid > curTop` → top=solid（洞穴顶）。
  3. **粗层级补全**：`lvl>curLvl && curTop<0 && top>curTop+32` → 接受粗层级。
- floor：最高非水固体，需低于 top。
- 无 top 时：用 solid 作 top（水）；否则 MIN。
- 最终包：`fillHoles`（内部洞用邻域中位数）、`denoise`（可选中值）。

## 3. 渲染管线（renderColor，loader 线程）

1. 解包 pixels → topArr/floorArr/isWater。
2. 补洞（可选）。
3. 去噪（可选）。
4. 平滑（3×3 两次，海陆分开）。
5. 水深（BFS 从海平面向下，10 级）。
6. 海洋模糊（box blur，仅水，2 遍 R=8）。
7. 等高线（仅陆地；自适应间隔 max(10,(hi-lo)/contourDensity)）。
8. 群系边界 + 标签（generateBiomeOverlay）。
9. 主循环：`MapStyles.landColor/waterColor` + hillshade。

scratch 缓冲在这些顺序阶段间复用（见踩坑记录 6）。

## 4. 纹理

| 纹理 | 注册名 | 说明 |
| --- | --- | --- |
| 主地图 | `voxymap:map` | 全分辨率 |
| 小地图 | `voxymap:map_small` | 1/4 box-filter，zoom*uiScale<0.5 时用 |
| 群系边界 | `voxymap:map_biomes` | 全分辨率 NativeImage（蓝线 4/6 虚线 pattern） |

释放：`releaseTextures()`（TextureManager.release + biomeImage=null）。

## 6. 文件职责

| 文件 | 职责 |
| --- | --- |
| `MapData.java` | 数据层：RocksBridge 读 Voxy、合并、缓存、异步渲染、纹理、高/群系查询 |
| `MapScreen.java` | 界面：绘制、缩放拖拽、交互菜单、标签、箭头、弹窗 |
| `MapStyles.java` | 6 套配色 + landColor/waterColor |
| `VoxyMapConfig.java` | 客户端配置（ModConfigSpec） |
| `VoxyMapMod.java` | 入口：按键、client tick、登录重置 |
| `RocksBridge.java` | 反射访问 Voxy 自带的 rocksdbjni |

## 7. 线程模型

- 数据解码/合并/渲染：`loader` 单线程（`ExecutorService`）。
- 纹理上传：主线程（`mc.execute`）。
- `renderColor` 在 loader 线程产生 rgb 数组 → 主线程 uploadTexture。
- tick（自动刷新）在主线程。
